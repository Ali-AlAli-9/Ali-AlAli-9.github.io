Employee AI Search

AI / Internal Search

An internal, Arabic-first search engine for employee documents: upload PDF, DOCX, Markdown or TXT files, index them locally, and get answers with source-and-page citations in Arabic and English. Hybrid BM25 + vector retrieval gives every document its own top-K slot before results are merged, then reranks and expands sections; the query cache is invalidated on each upload or delete. When the evidence is weak, it says it couldn't find an answer instead of inventing one.

FastAPI backend behind a Next.js 14 RTL interface with a same-origin proxy. Workspaces isolate every document, chunk, query and user list, with invite-code registration, owner/admin/member/viewer roles, Supabase Auth, encrypted per-workspace AI keys and bring-your-own-key support. Files above 4 MB are uploaded in checksum-verified chunks, and citations use real PDF page labels rather than numbers guessed from the text. 230 backend tests + 40 frontend tests.

FastAPI Next.js 14 PostgreSQL Supabase Auth BM25 + Vectors Docker Vercel

Clinic Agent — AI Voice Appointment System

AI / Messaging
Try it live on Telegram: @clinic33bot
Note: after your first message, please allow about a minute while the free hosting wakes up.

Multichannel AI booking agent for medical clinics that lets patients book, cancel, and manage appointments by texting or speaking in natural language — all through the messaging apps they already use. The patient sends *"Book me with Dr. Sara tomorrow at 10"* and the assistant handles the rest.

Key Features & Services

  • Natural-language booking: full three-part name, doctor conflict checks, per-doctor working hours, past dates rejected, and a forward booking window — at most 2 upcoming appointments per account inside the next 30 days, so expired bookings never block a new one (admins exempt).
  • Voice-first support: patients send a voice note → transcribed by Google's newest Gemini, the same model the agent itself runs on → the reply comes back as a clear audio message (free Edge TTS, Jordanian female Fusha voice) or as text. Text is the default; once the patient asks for voice, every later reply stays voice until they switch back, and the TTS client retries transient network failures instead of dropping the audio.
  • Multichannel: Telegram and WhatsApp through one unified gateway — switch with a single .env line.
  • Full lifecycle: cancel by description with explicit confirmation, upcoming list, and a searchable archive.
  • Tasks & reminders: add, list, and complete user tasks.
  • Admin toolkit (via chat): view any doctor's bookings, delete (day / hour-range / single / per account), block & unblock users, and broadcast or message specific accounts.
  • Human hand-off: when the patient asks for a person, every admin receives an instant notification with the patient's name and a tap-to-open link to the chat — raw account numbers are never exposed.

Security & Privacy

  • Medical notes encrypted with Fernet at rest — private data never appears in plaintext.
  • Admin identity is server-side and un-spoofable, plus a server-side per-account daily cap to protect the AI quota.
  • Signed Telegram webhook (secret in the URL path) and HMAC-verified WhatsApp webhook — unauthenticated requests are rejected before touching the system.
  • Brute-force protection on the admin panel (5 failed logins → 30-minute lockout) via django-axes.
  • Rate limiting + message dedup on every message through the unified gateway; media handled fully in-memory (never written to disk).

Eye AI Surveillance

AI / Real-time

Real-time AI surveillance system running on Uvicorn ASGI server with Django Channels WebSockets. YOLOv8 object detection + ByteTrack tracking + facenet-pytorch face recognition (MTCNN + InceptionResnetV1). Camera feed → motion detection → YOLOv8 → face recognition → WebSocket live stream → Django dashboard with automatic alerts. DB resilience (graceful degradation on connection loss), Supabase cloud support, auto-cleanup (48h data retention), brute force protection (5 attempts → 15 min lockout), CSP headers, audit logging. Manual engine start/stop from admin dashboard.

Closed system — only accounts created by the admin (staff) can access the dashboard.

Smart Solar Tracker

Embedded / Control

Sugeno fuzzy logic-based solar panel tracking system. Designed and modeled in MATLAB/Simulink with a custom 15-rule fuzzy inference engine, then auto-generated to C via Embedded Coder and deployed on Arduino Uno. Hand-optimized Arduino sketch with no external libraries featuring LDR-based light sensing, low-pass filtering, and smooth-step servo control — reducing response time from 9.5s to 3s.
